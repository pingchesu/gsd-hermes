## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command markdown -> Hermes skill frontmatter | Source command metadata becomes Hermes slash-command discovery metadata |
| install path replacement -> runtime execution | Wrong path replacement can make loaded skills reference the wrong runtime tree |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | S | Hermes skill names | mitigate | Require generated frontmatter `name: gsd-*` and test `gsd-help` specifically so Hermes command names cannot drift silently |
| T-03-02 | T | path replacement | mitigate | Assert generated Hermes skills contain no `~/.claude`, `$HOME/.claude`, or `./.claude` references |
| T-03-03 | R | install branch ownership | mitigate | Add a Hermes-named converter wrapper so future diffs can distinguish Hermes behavior from Claude skill migration behavior |
</threat_model>
