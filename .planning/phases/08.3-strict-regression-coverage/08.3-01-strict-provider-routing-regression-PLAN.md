# Plan 8.3-01: Strict Provider Routing Regression Coverage

<objective>
Add credential-free regression coverage that locks the v1.8 provider-routing contract: Claude-family model overrides must select Claude Code CLI, OpenAI/GPT model overrides must select Codex CLI, unsupported providers must fail fast, and no test/workflow path may silently reroute OpenAI bindings through `claude -p` or Claude bindings through `codex exec`.
</objective>

<context>
Phase 8.1 introduced SDK `agent_execution_bindings`. Phase 8.2 introduced provider-cli command rendering and `/gsd-execute-phase` dispatch guidance. Phase 8.3 must convert that behavior into durable regression gates so future upstream syncs or workflow edits do not recreate the original failure mode:

```text
model_overrides.gsd-executor = "openai/gpt-5.5"
→ incorrectly executed through claude -p
```

Current `.planning/config.json` intentionally exercises a mixed-provider setup:

```text
gsd-executor → openai/gpt-5.5 → codex-cli / gpt-5.5
gsd-verifier → anthropic/claude-opus-4-7 → claude-cli / claude-opus-4-7
```

Do not require live Anthropic/OpenAI/Codex credentials. Normal CI must prove deterministic resolver/command/workflow routing, not remote provider wire-level execution.
</context>
