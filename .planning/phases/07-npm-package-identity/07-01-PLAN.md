# Phase 7 Plan 01: Establish npm package identity

## Goal

Make `gsd-hermes` installable through npm/npx as its own package while keeping
the upstream installer behavior and compatibility command available.

## Tasks

- Update package metadata from upstream `get-shit-done-cc` identity to the
  downstream `gsd-hermes` repository and npm package identity.
- Add a `gsd-hermes` executable bin while preserving the `get-shit-done-cc`
  compatibility bin for source/global installs.
- Update the installer help, Hermes docs, and README entry points so new users
  see `npx gsd-hermes` as the primary install command.
- Add regression coverage for package identity, Hermes docs included in npm
  package files, and updated Hermes lifecycle docs.
- Verify targeted Hermes compatibility, full tests, and npm pack output.
