# gsd-hermes v1.8.0 — Provider-Routed Agent Execution

## Summary

`gsd-hermes@1.8.0` is planned as the provider-routed agent execution release. It lets Hermes projects use `model_overrides` as strict per-agent provider intent so `/gsd-execute-phase` can route different GSD agents through the matching external CLI.

The target operator outcome is:

```text
model_overrides.gsd-executor = "openai/gpt-5.5"
→ codex exec --model gpt-5.5

model_overrides.gsd-verifier = "anthropic/claude-opus-4-7"
→ claude -p --model claude-opus-4-7
```

Unsupported providers, unavailable CLIs, missing CLI model values, or missing CLI authentication fail fast instead of silently falling back to the parent model or another provider CLI.

## Operator configuration

```json
{
  "runtime": "hermes",
  "resolve_model_ids": "omit",
  "workflow": {
    "agent_execution_router": "provider-cli",
    "cross_ai_execution": false
  },
  "model_overrides": {
    "gsd-executor": "openai/gpt-5.5",
    "gsd-verifier": "anthropic/claude-opus-4-7"
  }
}
```

## CLI route table

| Model override family | Provider family | Execution driver | Command shape |
| --- | --- | --- | --- |
| `openai/*`, `gpt-*`, `o3`, `o4-*` | OpenAI/GPT | `codex-cli` | `codex exec --model {cli_model}` |
| `anthropic/*`, `claude-*`, `opus`, `sonnet`, `haiku` | Anthropic/Claude | `claude-cli` | `claude -p --model {cli_model}` |

## Proof boundary and limitations

Provider-cli execution proves deterministic GSD command routing and normalized CLI `--model` arguments. It does not prove the wire-level request that Codex CLI, Claude Code CLI, OpenAI, or Anthropic ultimately sends after the external process starts.

Hermes native `delegate_task(model=...)` proof is separate. Native delegate proof shows a child `AIAgent(model=...)` is constructed with the configured model when GSD uses Hermes child spawning. Provider-cli proof shows GSD intentionally chose an external CLI driver and model argument for a configured provider family.

`workflow.cross_ai_execution` remains a legacy whole-plan fallback. It is lower priority than valid `provider-cli` agent bindings and must not silently override them.
