# GSD Hermes v1.14.0 — upstream 73f7ad33 sync

## Summary

`gsd-hermes@1.14.0` is a routine downstream sync to `gsd-build/get-shit-done@73f7ad33`, importing 72 upstream commits since the v1.13.0 base `3579a48d` while preserving the Hermes-first package identity and strict provider-routed execution guarantees.

## Imported upstream highlights

- GSD v1.41.0 maintenance and feature work, including atomic hook builds, Homebrew Node path hardening, milestone archive layout support, MVP/TDD workflow additions, canary stream documentation, workflow/docs updates, and expanded regression coverage.
- New/updated command surfaces and workflow docs from upstream, including MVP-phase flow and command consolidation material.
- SDK/config improvements such as workstream config inheritance and additional query/runtime coverage.

## Downstream guarantees preserved

- Package name remains `gsd-hermes` and the npm/GitHub release line remains independent from upstream `get-shit-done-cc`.
- Hermes local mode remains project-linked: `./.gsd-hermes/skills` plus Hermes `skills.external_dirs`.
- `model_overrides` remain the canonical per-agent model intent source.
- `hermes/*` routes stay Hermes-native, pass an unqualified model token, and do not pass `--provider`; provider selection stays with the configured Hermes provider.
- Direct `openai/*`/`gpt-*` routes stay on Codex CLI, direct `anthropic/*`/`claude-*` routes stay on Claude Code CLI, and unsupported bindings fail fast instead of silently falling back.
- `cross_ai_execution` remains a lower-priority legacy fallback and does not override valid provider-routed bindings.
