# GSD Hermes v1.12.0 — Routine upstream sync to 42ed7cee

## Summary

`gsd-hermes@1.12.0` syncs the downstream fork with `gsd-build/get-shit-done` `upstream/main@42ed7cee`, importing 24 upstream commits since the previous synced base `f2decefe` while preserving the Hermes-first downstream package identity.

This release keeps the simplified Hermes routing model from v1.11:

- `model_overrides` remain the source of per-agent model intent.
- `hermes/gpt-5.5` and `hermes/claude-opus-4-7` route through Hermes-native execution.
- Hermes-native routes pass unqualified model tokens to `hermes chat` and do not pass `--provider`.
- Direct `openai/*` and `anthropic/*` overrides continue to use provider-specific CLI routes.
- `cross_ai_execution` remains a lower-priority legacy fallback and must not override valid per-agent bindings.

## Upstream highlights imported

The upstream sync includes maintenance and architecture work from `get-shit-done`, including:

- per-phase-type model mapping support;

- Gemini duplicate local command avoidance;
