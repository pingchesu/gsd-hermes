# GSD Hermes v1.13.0 — Routine upstream sync to 3579a48d

## Summary

`gsd-hermes@1.13.0` syncs the downstream fork with `gsd-build/get-shit-done` `upstream/main@3579a48d`, importing 135 upstream commits since the previous synced base `42ed7cee` while preserving the Hermes-first downstream package identity.

This is a routine upstream alignment release. It carries the latest upstream fixes around command/workflow routing, state and milestone robustness, SDK query/runtime bridge seams, command contract validation, worktree path safety, and documentation/test parity.

## Preserved downstream guarantees

- Public package identity remains `gsd-hermes` / `npx gsd-hermes`.
- Hermes global install and project-linked local install semantics remain intact.
- `model_overrides` remains the source of per-agent model intent.
- `hermes/*` overrides route through Hermes chat/tool execution without passing `--provider`; the configured Hermes provider decides the wire-level provider.
- Direct `openai/*` / `gpt-*` overrides still route to Codex CLI, and direct `anthropic/*` / `claude-*` overrides still route to Claude Code CLI.
- Unsupported/unavailable execution paths must fail fast with actionable diagnostics instead of silently falling back to the wrong CLI.
