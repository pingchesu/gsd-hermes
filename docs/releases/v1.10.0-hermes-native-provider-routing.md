# GSD Hermes v1.10.0 — Hermes-native provider routing

Release date: 2026-05-03

## Summary

`gsd-hermes@1.10.0` extends strict provider-routed execution with explicit Hermes-native drivers while keeping the existing Codex/Claude CLI routes intact.

The core contract remains unchanged: `model_overrides` is the source of per-agent model intent, and provider-routed execution either uses the selected driver or fails fast. It must not silently fall back to `claude -p`, `codex exec`, the parent Hermes session model, or `workflow.cross_ai_execution`.

## Added

- `workflow.agent_execution_driver` for provider-routed execution:
  - `provider-cli` — default; OpenAI/GPT routes to Codex CLI and Anthropic/Claude routes to Claude Code CLI.
  - `hermes-chat` — routes supported provider families through `hermes chat --model ... --provider ...`.
  - `hermes-terminal-tool` — routes through `hermes chat` with `--toolsets terminal,file` for code-writing executor work.
- SDK `agent_execution_bindings.driver_preference` so init payloads show the selected execution surface before dispatch.
- Dispatcher command rendering and preflight for Hermes-native drivers, including missing-`hermes` fail-fast diagnostics.

## Preserved guarantees

- `openai/gpt-5.5` with default `provider-cli` still renders `codex exec --model gpt-5.5`.
- `anthropic/claude-opus-4-7` with default `provider-cli` still renders `claude -p --model claude-opus-4-7`.
- Hermes-native drivers preserve the fully-qualified configured model token (for example `openai/gpt-5.5`) instead of normalizing it for provider-specific CLIs.
- `workflow.cross_ai_execution` remains a lower-priority legacy fallback and does not override valid provider-routed bindings.

## Configuration example

```json
{
  "runtime": "hermes",
  "resolve_model_ids": "omit",
  "workflow": {
    "agent_execution_router": "provider-cli",
    "agent_execution_driver": "hermes-terminal-tool",
    "cross_ai_execution": false
  },
  "model_overrides": {
    "gsd-executor": "openai/gpt-5.5",
    "gsd-verifier": "anthropic/claude-opus-4-7"
  }
}
```
